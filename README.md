AI Asistan Projesi
===================

Bu proje; iş, sağlık, finans, hedefler, blog, sosyal, zeka oyunları ve alışveriş modüllerini tek bir akıllı asistan altında toplayan çok modüllü bir uygulama içindir.

Bu klasör altında şu anda yalnızca **backend (Java / Spring Boot)** iskeleti bulunur. Daha sonra `frontend-web` (React) ve `mobile` (React Native) klasörleri eklenebilir.

Klasör yapısı (hedef):

- `backend/` – Spring Boot REST API
- `Görseller/` – UI tasarım görselleri

Backend tarafı, PostgreSQL veritabanı için `schema.sql` dosyasında tanımlanan şemayı kullanır.
